# 09 身份权限与安全边界

阶段：P0 · 来源：贯穿要求、B1 / B2 / B6 / B7 / B11、C7 / C8

导航：[总览](00-overview.md) · 依赖：[提交](04-plans-submission.md)、[运维](12-operations.md)

## 1. 身份模型

原稿已定：单实例单团队、仅管理员和成员、初始化时设置管理员、其余通过邀请加入、不开自注册。结果团队共享，提交保留个人身份。

设计建议 P0 使用本地账号与密码；密码使用 Argon2id 加盐哈希，保存算法 / 参数版本，邀请令牌单次有效并有到期时间。OIDC / SSO 暂不实现。初始化入口只在尚无管理员时有效，首个管理员创建完成后关闭，不能通过重启重新开放。

| 编号 | 要求 |
| --- | --- |
| IAM-01 | 会话与 PAT 明确区分，所有业务授权在服务端执行 |
| IAM-02 | PAT 只读或实验两类，永不具备管理员能力 |
| IAM-03 | 写操作记录用户、PAT、对象、动作、结果和请求 ID |
| IAM-04 | 凭据明文不返回，不进入快照、导出或普通日志 |
| IAM-05 | 执行容器按阶段限制网络、挂载与资源 |
| IAM-06 | 账户停用、PAT 撤销 / 过期及时阻止后续请求 |

## 2. PAT 规则

权限计算：有效用户权限 ∩ PAT scope ∩ PAT 允许动作 ∩ 对象归属。管理员创建的 experiment PAT 仍只能做成员级实验操作。

PAT 由本人在网页创建、查看元信息和撤销，生成时仅展示一次原始 token；数据库只保存 token_hash 与非敏感标识前缀。PAT 不能创建、撤销 PAT，也不能邀请成员或修改团队设置。

- read：读取团队业务目录、运行、配置的脱敏业务部分、评分与产物。
- experiment：read 加创建 / 修改自己的方案、批次、集合、上传附件、提交与管理自己的运行。
- 每个 PAT 必须有 expires_at 和 run_limit，服务端原子统计 accepted_runs。
- 撤销或到期不自动终止既有运行；本人网页或管理员另行取消。用户被停用时同样停止后续调用，管理员决定如何处置在途工作。
- 续期或增额只由本人网页操作且受团队上限约束，记录审计；不能让 PAT 自行续期。

## 3. 权限矩阵

“本人”以资源 owner_id 匹配，不能由请求参数伪造。“管理覆盖”是停用、取消或维护能力，不代表管理员可以无痕改写别人的实验记录。

业务导出是读取能力的异步实现，read PAT 可以发起，仍受导出规模和请求频率限制，不消耗运行提交额度。导出不包含管理员备份或凭据材料。

管理员接口不仅检查 role=admin，还要求 auth_channel=web_session。PAT 请求统一拒绝为 ADMIN_SESSION_REQUIRED；将 scope 改成字符串“admin”不能获得权限。普通成员不能通过可写资源间接指定任意宿主路径、服务端 endpoint 或管理命令。

“准备仅管理员”限于首次建立准入及其重试。已准入任务的缓存恢复、成员上传附件的 bootstrap 安装属于已授权运行，由系统内部身份执行固定规格；不增加管理 API 权限，也不提供 PAT 单独恢复缓存或执行任意准备脚本的入口。审计关联原用户 / PAT、运行、试次和共享恢复 Operation。read PAT 可查询进度，但不能触发运行；等待者只能取消自己的运行，不能取消其他运行仍需的共享恢复。

## 4. 会话、凭据与审计

网页会话建议使用 HttpOnly、Secure、SameSite cookie；写操作防 CSRF。对外部署需要 TLS，可由反向代理终止。登录、邀请和令牌接口做基本速率限制。

业务凭据使用主密钥做 AES-GCM 认证加密；每条密文使用不重复的随机 nonce，保存 key_version 和认证标签，主密钥放独立受保护文件，仅服务账户可读。可将凭据身份与修订作为附加认证数据，避免密文被错误替换到另一记录。普通配置保存引用；管理员可以替换值而不能回读明文。凭据轮换不改变历史配置，actual_execution 记录本次使用的凭据修订标识，避免保存密文或值摘要到公开结果。

备份数据中可包含凭据密文，但不能包含主密钥；主密钥单独保存和转移。完整备份下载不属于普通业务读取，只有管理员维护入口可操作；“凭据只写不读”不妨碍受控的密文备份。

审计事件包括登录 / 授权失败、PAT 创建 / 撤销、额度变更、提交与取消、配置变更、准入确认 / 撤销、缓存恢复 / 回收、附件安装、凭据轮换、产物回收与维护。建议首期不自动清理操作记录和审计元数据；如后续设保留期，须同时更新 API 和恢复策略。访问日志与业务审计分开，避免用轮转日志替代持久记录。

## 5. 容器与阶段网络

原稿已定：准备阶段需要外网，执行和验证阶段只能访问模型提供商；团队成员受邀且可信，基础脱敏从宽。

本轮优先复用 Harbor 的分阶段网络策略，不再把自建出口代理作为首期组件。官方文档确认 [environment] 是启动基线，[agent] 应用于 agent.run()，[verifier] 应用于 verify()；agent.setup() 仍使用环境基线，不自动继承执行阶段限制。

| 阶段 | 网络 | 文件与凭据 |
| --- | --- | --- |
| 准备 / agent.setup | 环境基线可为 public，用于安装依赖和 bootstrap；仍遵守作者硬约束 | 仅必要下载凭据，不挂载主密钥 |
| 执行 / agent.run | allowlist，仅批准的模型服务；不需要模型联网时可 no-network | 任务副本、工作目录、当前模型凭据 |
| 验证 / verify | 优先 no-network，确需模型验证时 allowlist 为明确模型服务 | 任务输出和只读验证材料，不暴露服务管理资源 |

Harbor 的 Docker 实现借助 egress-control sidecar 与 Linux nftables 内核能力提供 allowlist / 动态策略。安装和预检必须验证 network_allowlist、dynamic_network_policy 及具体主机能力；不支持时返回 NETWORK_POLICY_UNSUPPORTED，不静默降为 public。只检查 nft 命令是否存在不足以证明策略可用。

团队限制与任务声明取更严格的结果：public 任务也须收紧到团队批准的模型范围，任务已有更严策略则继续保留；no-network 与必需模型调用冲突时拒绝并解释。官方 job config 的 extra_allowed_hosts 是扩展字段，不能当作收紧开关。如何覆盖任务策略需用锁定版本原型验证；必要时由 Runner 生成临时生效任务配置，保留原始与生效摘要，不改写作者版本。无法可靠收紧时阻塞运行。

验收需确认不能直连任意外网、宿主管理面或云元数据地址，并确认准备到执行 / 验证的策略切换实际生效。模型服务端 web 工具和任意 MCP 服务并不完全由容器网络控制；首期禁用不符合边界的远程工具，不能将 nftables 限制夸大为对模型服务端行为的全面控制。

附件 bootstrap 仅在所属试次容器执行，不挂载宿主机目录（执行器为本试次输出挂载的日志与产物目录除外，[14](14-decisions.md) U-16）；固定输入通过环境文件传输复制，输出通过存储接口收集。安装阶段允许按准备策略访问外网，受安装超时和运行总时限约束；进入执行 / 验证后切换到模型服务限制。P0 每试次独立安装，失败不改变其他试次或数据集准入。

容器不挂载 Docker socket、实例数据库、主密钥或宿主目录（执行器为本试次输出挂载的日志与产物目录除外，[14](14-decisions.md) U-16）；容器内输入和验证材料优先只读，工作目录独立可写。设置 CPU、内存、PID 和磁盘使用限制，不使用 privileged 模式。需要特殊权限的任务在 P0 返回不支持。M1 实测 Harbor 的文件传输是复制，附件不经挂载；Harbor Docker 环境会把本试次的输出目录可写挂入容器，按 U-16 接受，这些目录只属于本试次，结束后作为产物收集。

Harness 与任务代码位于同容器时，模型凭据可能被任务代码读取，这是原稿可信团队假设下的已知限制；不宣称对恶意任务具有强隔离。基本脱敏覆盖已注入 token、常见 Authorization 字段及 URL 敏感参数，无法保证识别经过编码或变形的秘密。

## 6. RSI 扩展边界

首期 PAT 的 read 包含完整业务证据，不承诺隐藏参考答案或验证代码。后续若支持留出集，需要新增字段级材料权限、结果可见策略与专门评测空间，不能仅靠隐藏网页入口实现。领域模型预留 artifact classification 与 dataset visibility_policy 字段即可，P0 不实现专用 RSI 授权。

## 7. 验收

- 管理员 PAT 请求全部管理接口仍被拒绝，普通管理员网页会话可执行。
- 成员可读他人结果但不能取消他人运行；篡改 owner_id 无效。
- 撤销 PAT 后下一次调用失败，已受理运行按既定规则继续。
- experiment PAT 可通过已受理运行恢复缓存和执行容器内 bootstrap，无需管理员；read PAT 不能触发这些工作，任一等待者不能取消他人共享恢复。
- 快照、导出、错误、API 响应和普通日志不出现已知凭据明文。
- 容器执行 / 验证阶段的 Harbor 原生策略阻止任意外网与宿主管理面，仍能调用已允许模型服务；无 nftables 支持时明确拒绝。
